# TFT Forge

TFT Forge is a Teamfight Tactics tool site for checking TFT comps, champions, items, synergies, augments, team builder, and patch notes.

Website: https://tftforge.gg

## TFT Tools

- [TFT Comps](https://tftforge.gg/en/comps)
- [TFT Team Builder](https://tftforge.gg/en/team-builder)
- [TFT Champions](https://tftforge.gg/en/champions)
- [TFT Items](https://tftforge.gg/en/items)
- [TFT Augments](https://tftforge.gg/en/augments)
- [TFT Synergies](https://tftforge.gg/en/synergies)
- [TFT Patch Notes](https://tftforge.gg/en/patch-notes)
